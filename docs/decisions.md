# ScentLens decisions

Each entry: date, decision, reason.

- 2026-10-15. Dataset files observed on the hub (revision 9d2db452): perfumes.csv (12.1 MB, the file the card's data_files points to), images.zip (875 MB), plus parquet, xls, xlsx, sqlite, json, and jsonl copies of the metadata. Use perfumes.csv as the metadata source. Card tags: license mit, not-for-all-audiences.
- 2026-10-15. Read catalog images straight from images.zip instead of extracting, to save about 0.9 GB of disk.
- 2026-10-15. Disk budget estimate about 10 GB working set, 15 GB free requested for headroom: venv about 3 GB, model weights about 2.5 GB (dinov2 base, siglip 2 base, open_clip ViT B 32), dataset about 0.9 GB, embeddings and caches under 0.5 GB, fine tune checkpoints about 1 GB, real photos 1 to 2 GB, transient pip and build space about 2 GB (installs use no pip cache).
- 2026-10-15. Environment: CPython 3.11.13 managed by uv 0.8.22, venv in .venv. Top level pins in requirements.txt, full transitive lock in requirements-lock.txt, CI subset in requirements-ci.txt (adds scipy, which scikit-learn needs anyway and the calibrator uses for the Clopper Pearson bound). torch 2.14.1 with MPS available on the M3.
- 2026-10-15. Normalization adds a few obvious variants to the concentration list in the plan: eau de parfum, eau de cologne, extrait de parfum, extrait, edc, perfume. A repeated brand prefix inside the name is removed. A name that normalizes to nothing keeps its plain normalized form.
- 2026-10-15. Lenient line key removes flanker words (noir, sport, extreme, absolu, elixir, fraiche, night, nuit, summer, edition, limited, collector, platinum, black, rouge, blanc, pure, essence, light, plus articles such as le, la, de, eau). Full list in src/scent_lens/normalize.py.
- 2026-10-15. Bottle list matching: brand first (token set ratio at least 80), then name (token sort ratio) inside matching brands, score = 0.25 brand + 0.75 name. A match is "high" only when the top score is at least 92 and at least 5 ahead of the runner up; everything else is marked "check".
- 2026-10-15. Splits: catalog and non catalog bottles are split separately, each in brand interleaved order, so each brand and the unmatched group land in both pools. Folds are round robin over the same ordering.
- 2026-10-15. Abstention threshold: the lowest threshold on out of fold calibrated probability whose accepted set has a one sided 95% Clopper Pearson error upper bound at or below 1 minus the target selective accuracy. If none qualifies the system always abstains.
- 2026-10-15. A query whose truth is not in the gallery gets the maximum int64 rank so it is never a hit at any k. Found by a failing unit test (the first version used the gallery size, which counted as a hit at top 5 in a three product gallery). The code was fixed; the test kept its expectation.
- 2026-10-15. A threshold unit test asserted a value guess (t above 0.3) that the correct algorithm does not produce. It was replaced by stricter checks of the actual guarantee: the bound holds at t, every lower threshold violates it, and accepted accuracy is at least the target.
- 2026-10-15. perfumes.csv is pipe delimited with CRLF line ends and has no image_id column although the card lists one; image_id is the file name stem. One image per row verified: 26,283 rows with an image name, all present in the zip, no image name shared by two rows. 139 zip images are not referenced by the csv and are ignored. Design: retrieval with one reference per catalog row; after grouping rows into products, 2,172 products have 2 to 8 rows, and their extra images become extra gallery references.
- 2026-10-15. Duplicates. Byte identical images shared by different products (53 groups, 181 images, mostly one brand reusing one picture across its line) are generic brand images that cannot identify a product; they are dropped from the gallery. Within a product, byte identical or near duplicate (phash Hamming at most 4) copies keep one. phash near duplicates across different products (about 29.7k pairs) are kept: they are distinct products with near identical bottles, a real source of difficulty, which the lenient rule partly absorbs.
- 2026-10-15. Embedding input: pad to square with white, resize to 224, no center crop, so tall bottles keep cap and base. Same for all backbones and for real photos. CLIP is open_clip ViT B 32 laion2b s34b b79k.
- 2026-10-15. Embedding time on the M3 (MPS), measured on 1,024 images: CLIP 97 img/s, SigLIP 2 43 img/s, DINOv2 28 img/s. Full gallery about 30 min for all three, synthetic queries about 16 min more. Under the 4 hour limit, so no STOP B and no backbone dropped.
